# Cita Checker — проверка записи на TIE (toma de huellas)

Скрипт проверяет, есть ли свободная запись (cita previa) на портале
[icp.administracionelectronica.gob.es](https://icp.administracionelectronica.gob.es/icpplustieb/index.html)
для услуги получения карточки TIE после положительной резолюции:

- **«POLICÍA-TOMA DE HUELLAS (EXPEDICIÓN DE TARJETA), INICIAL, RENOVACIÓN,
  DUPLICADO Y LEY 14/2013»** — основной вариант;
- **«POLICÍA-EXPEDICIÓN DE TARJETAS CUYA AUTORIZACIÓN RESUELVE LA DIRECCIÓN
  GENERAL DE GESTIÓN MIGRATORIA»** — альтернатива для Мадрида, Барселоны и
  Пальмы (упомянута в AVISO 2 резолюции).

По умолчанию проверяются **оба** варианта во **всех** офисах провинции
Барселона. Скрипт **только проверяет** наличие слотов и шлёт уведомление —
он ничего не бронирует (финальный шаг брони требует SMS-код, бронируйте
вручную).

## Установка

Нужен Python 3.9+.

```bash
cd tools/cita-checker
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
```

## Использование

Посмотреть точные названия услуг на портале:

```bash
python cita_checker.py --list-tramites
```

Запустить проверку в цикле (каждые ~5 минут), с NIE и именем как в резолюции:

```bash
python cita_checker.py \
  --doc Y1234567X \
  --name "OLEG TEPLOV" \
  --country RUSIA
```

Разовая проверка (для cron и т.п.; код выхода: 0 — есть слоты, 1 — нет,
2 — ошибка):

```bash
python cita_checker.py --once --doc Y1234567X --name "OLEG TEPLOV"
```

С видимым окном браузера — чтобы решить капчу и **сразу забронировать**,
когда слоты появятся (рекомендуемый режим):

```bash
python cita_checker.py --headful --keep-open --doc Y1234567X --name "OLEG TEPLOV"
```

Данные можно передавать и через переменные окружения, чтобы не светить их
в истории шелла: `CITA_DOC`, `CITA_NAME`, `CITA_YEAR`, `CITA_COUNTRY`,
`CITA_OFFICE`, `CITA_PHONE`, `CITA_EMAIL`, `CITA_PROXY`.

### Полезные опции

| Опция | Что делает |
|---|---|
| `--province madrid` | другая провинция (по умолчанию `barcelona`) |
| `--tramite REGEX` | какой трамите искать (можно несколько раз); по умолчанию `TOMA DE HUELLAS` и `GESTION MIGRATORIA` |
| `--office REGEX` | проверять только офисы по маске (например `--office "RAMBLA"`) |
| `--max-offices N` | не больше N офисов на трамите (0 — все) |
| `--year 1990` | год рождения (некоторые формы его требуют) |
| `--interval 300` | пауза между циклами, сек (меньше 120 — риск бана IP) |
| `--headful` | показать браузер (капча, ручная бронь) |
| `--proxy http://…` | прокси (портал блокирует большинство VPN/датацентров) |
| `--telegram-token` / `--telegram-chat` | уведомление в Telegram (или env `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID`) |

## Уведомления

Когда слоты найдены: звуковой сигнал + системное уведомление macOS/Linux +
(опционально) сообщение в Telegram + скриншот страницы в `cita-debug/`.
По умолчанию после первой находки цикл останавливается
(`--no-stop-on-first`, чтобы продолжать).

## Важно знать

- **Запускайте с испанского домашнего/мобильного IP.** Портал сбрасывает
  соединения с датацентровых IP и большинства VPN. Если видите
  `blocked / rate-limited` — смените сеть или добавьте `--proxy` с
  резидентным прокси.
- **Капча.** В часы наплыва портал включает капчу — запускайте с
  `--headful` и решайте её вручную, скрипт подождёт до 5 минут.
- **Когда появляются слоты.** Чаще всего их выкладывают в начале рабочего
  дня (около 8–9 утра) и в начале недели; свободные слоты разбирают за
  минуты — поэтому режим `--headful --keep-open` с интервалом 3–5 минут в
  это время самый практичный.
- **Не занижайте интервал.** Частые запросы приводят к временной
  блокировке IP, после которой не зайти даже вручную. Минимум, который
  скрипт позволяет, — 60 секунд; разумный режим — 300.
- **Портал меняется.** Если скрипт пишет `unrecognized page`, смотрите
  дампы в `cita-debug/` — там скриншот и HTML страницы, на которой он
  запнулся.
- Телефон и email (`--phone` / `--email`) нужны только чтобы портал
  показал экран со слотами; бронь скрипт не завершает.
